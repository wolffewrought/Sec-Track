Unknown companies

A company logged that is on neither the contractor nor regular visitor list is held under Irregular visitors, on the Regular Visitors tab. Nothing interrupts the gate; classify them when there is time.

Export

A day with recorded shifts exports one sheet per shift by default, each covering only that shift's movements. Tick the box above to get a single sheet for the whole day instead. Every export carries the records inside it, so any of these can be restored on another device. The day sheet holds one day only — to carry a whole stint off site use a period report below, or a backup file for everything.

Row colours

Tap the number beside any entry to colour it. Name the colours here and the meanings print on the reports.

Period report

A week or month report lists every movement day by day. Longer periods give daily totals and the most frequent visitors instead, so the file stays manageable. Contractor inductions and regular visitors are included either way.
